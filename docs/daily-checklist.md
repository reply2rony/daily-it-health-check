# Daily IT Health Check — checklist (starter template)

Run these in order each morning. Tick each one off in the log CSV.

1. Internet and office network — is the connection up, and can a
   sample workstation reach the internet?
2. Servers / shared drives — are shared folders reachable?
3. Backups — did last night's backup report a success?
4. Printers and scanners — do the shared printers respond?
5. Email and shared apps — can a test account sign in?
6. Updates — are any urgent security updates waiting?
7. User issues — check the helpdesk queue for overnight tickets.
8. Log it — record every result, even "OK". A gap in the log is itself
   a finding: an unchecked system cannot be called healthy.

If anything fails, log it as "Needs attention", tell the person
responsible for that system, and re-check it before the end of the day.
This checklist is a learning template, not a production monitoring
system and not a claim of production use.
